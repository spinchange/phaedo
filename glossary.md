# Phaedo Translation Glossary

Working choices from the style sample and batches 1–3. Context-sensitive alternatives are recorded rather than forced into one English word.

| Greek term | Current rendering | Usage note |
|---|---|---|
| ψυχή (*psychē*) | soul | Use consistently in the soul/body and survival arguments. |
| σῶμα (*sōma*) | body | Keep distinct from *psychē*. |
| φάρμακον (*pharmakon*) | poison / drug | “Poison” in reports of Socrates’ death; “drug” in practical instructions about taking it. |
| λόγος (*logos*) | conversation / account / argument | Choose by context; do not impose a single rendering. “Reasoning” is used where the passage specifically concerns reasoning. |
| μῦθος (*mythos*) | story / fable | Preserve the contrast with arguments where it matters. |
| θεωρία (*theōria*) | sacred voyage / sacred delegation | Use “sacred voyage” for the Delian observance as an event, and “sacred delegation” for the group or mission. |
| ἡδύ / λυπηρόν (*hēdy / lypēron*) | pleasure / pain | Established in the style sample at 60b–c. |
| φιλοσοφία (*philosophia*) | philosophy | Consistent across the sample and batch 1. |
| μουσική (*mousikē*) | music | “Philosophy is the greatest music” preserves the dream’s wordplay at 60e–61a. |
| φρόνησις (*phronēsis*) | wisdom / understanding | Batch 2 uses “wisdom” for the philosopher’s aim; batch 3 uses “understanding” for a capacity of the soul. Review context when later occurrences are added. |
| γένεσις / γίγνεσθαι (*genesis / gignesthai*) | coming-to-be / come to be / be born | Render contextually; retain the reciprocal generation central to the argument at 70–72. |
| ἀναβιώσκεσθαι (*anabiōskesthai*) | coming back to life | Use for return from death to life in the cyclical-generation argument. |
| ἐναντίον (*enantion*) | opposite | Keep the term visible in the argument from opposites. |
| Ἅιδης (*Haides*) | Hades | Retain the Greek name for the destination of the dead. |
| ἀρετή (*aretē*) | virtue | Batch 2 distinguishes genuine virtue from apparent virtue. |
| σωφροσύνη (*sōphrosynē*) | self-control | Current rendering in batch 2. |
| ἀνδρεία (*andreia*) | courage | Current rendering in batch 2. |
